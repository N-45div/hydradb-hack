HydraDB Hackathon · Track 2: agent context layer

Compaction that learns.

pagefault is a Rust compaction API for coding agents. When the context window fills, it pages history out to a HydraDB graph instead of summarizing it away. It then traverses the graph to page back in what the next step will need, and every miss (a page fault) teaches the graph for next time.

Benchmark: page faults on held-out sessions

Real SWE-agent runs, replayed with an 8k context limit. At each compaction every policy keeps 2k tokens of evicted history. A page fault is the agent re-opening a file, re-running an unchanged command or repeating a search that compaction dropped. Test sessions are different issues from anything the graph learned from. Mean of 5 training orders; the band is ±1 std.

How it works

1 · CaptureEvery tool call becomes graph entities, with no LLM involved: files, commands, searches, errors and traceback symbols.
2 · Page outAt compaction, old steps leave the window but stay in HydraDB, linked by CO, MENTIONS, NEXT and FIXED_BY edges.
3 · Page inTraverse from the entities in focus (session graph plus repo graph). Score candidates and restore the steps that show them within budget.
4 · LearnPage faults create NEXT edges and wasted restores weaken them. Per-repo feature weights are fitted online and stored back in HydraDB.

Use it from any harness

pi extension included. Anything that can POST tool calls works: Claude Code hooks, Codex, Rust pi ports, MCP clients.

# start a session, stream tool calls, compact when the window fills
curl -X POST $PAGEFAULT/v1/sessions -d '{"repo":"acme/api","harness":"pi","model":"qwen3-coder"}'
curl -X POST $PAGEFAULT/v1/sessions/$ID/events -d '{"events":[{"tool":"read","args":{"path":"src/auth.py"},"output":"..."}]}'
curl -X POST $PAGEFAULT/v1/sessions/$ID/compact -d '{"keep_recent_tokens":2000,"budget_tokens":2000}'   # -> summary_md + kept steps + why
curl "$PAGEFAULT/v1/sessions/$ID/recall?q=config.py"                                                   # page fault: fetch + learn
curl -X POST $PAGEFAULT/v1/sessions/$ID/check -d '{"command":"pytest tests/test_auth.py"}'             # "already failed, nothing edited"
curl -X POST $PAGEFAULT/v1/sessions/$ID/end -d '{"resolved":true}'                                     # learn from this session
